One line a phone battery texts the charger it waited all day for — built for make.fun's "The Battery's Last Text to Its Charger" bounty (max 200 characters).

> hey. it's me. 1%. i waited all day for you, so consider this my two weeks' notice — effective 1%.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it. No dependencies, Python 3 only.
